# JSON Server Product Management

React product management practice with a local JSON dataset.

## Project structure

- `db.json`
- `src/Components/ProductManagement.jsx`
- `src/App.jsx`

## Getting started

```bash
git clone https://github.com/JAYANTI-THAKOR-941/JSON-SERVER.git
cd JSON-SERVER
```

Install dependencies with `npm install`, start the JSON API according to the package configuration, and run `npm run dev`. Match the API endpoint used in the source.
